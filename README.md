# Reading proofs

How we read and understand proofs written for machines. A reader's account, not the authors'.

- `riemann/`: the architecture of Levent Alpöge's formal proof of the Riemann Hypothesis, announced in November 2026, as we read it. Not peer reviewed. `riemann/map.html` is generated from `riemann/board.json` by `python3 build.py` run inside `riemann/`.

Corrections are welcome as issues.

Andrey Lazarev, mathematician by training, Candidate of Sciences (PhD) in Physics and Mathematics.

The checks

Numbers we computed while reading, to see that a claim holds where we could test it. Each check is a short program in plain Python; the numbers below are what it prints.

The architecture of a proof   The map

These are sanity checks, not part of the proof and not proofs of anything. A check that agrees shows that we read a statement correctly, or that an identity holds in the cases we tried. The live checks on the other pages are listed at the end.

The factorial misses Euler's constant

On the size page we say that the factorial cannot serve as the proof's object: its size and its divisibility come from the same formula, and it misses the term γ·a that the true prime count contains. By Legendre, ln(a!) is the sum of Λ(n)·⌊a/n⌋. The prime count wants Λ(n)·(a/n − 1), whose main term is a ln a − (1 + γ)a. The program measures the difference per unit of a, and the average fractional part that causes it.

# The factorial misses Euler's constant.
# ln(a!) = sum over n <= a of Lambda(n) * floor(a/n)  (Legendre).
# The true prime count wants sum of Lambda(n) * (a/n - 1), whose main term is
# a ln a - (1 + gamma) a.  The difference per unit of a tends to gamma.
import math

GAMMA = 0.5772156649015329

def mangoldt_table(N):
    lam = [0.0] * (N + 1)
    sieve = bytearray([1]) * (N + 1)
    for p in range(2, N + 1):
        if sieve[p]:
            for k in range(p * p, N + 1, p):
                sieve[k] = 0
            q = p
            while q <= N:
                lam[q] = math.log(p)
                q *= p
    return lam

N = 10**6
lam = mangoldt_table(N)
for a in (10**3, 10**4, 10**5, 10**6):
    lnfact = math.lgamma(a + 1)
    frac = sum(lam[n] * ((a / n) % 1) for n in range(2, a + 1)) / a
    gap = (lnfact - (a * math.log(a) - (1 + GAMMA) * a)) / a
    print(a, round(frac, 4), round(gap, 4))
print("1 - gamma =", round(1 - GAMMA, 4), " gamma =", round(GAMMA, 4))

Nair and Chudnovsky stop at 0.99

Among the simpler objects we tried in place of the ladder were the auxiliary polynomials of Gelfond and Schnirelmann. In many variables, as Nair and Chudnovsky set it up, the object is a Hankel determinant D whose size comes from Selberg's integral. The method gives a lower bound for the summed prime count with a constant just below 1.

# Nair and Chudnovsky: a Hankel determinant from Selberg's integral.
# D = prod_{j<n} j! * ((A+j-1)!)^2 / (2A+n+j-2)!,  A = [s n],  s = 0.39191162.
# The method gives psi1(2A+2n) - psi1(2A+n) >= -ln D, psi1(x) = sum_{k<=x} psi(k),
# whose main term is ((2A+2n)^2 - (2A+n)^2) / 2.  The ratio tends to 0.99035, not 1.
import math

s = 0.39191162
lf = lambda k: math.lgamma(k + 1)
for n in (200, 500, 1000, 2000, 4000):
    A = int(s * n)
    lnD = sum(lf(j) + 2 * lf(A + j - 1) - lf(2 * A + n + j - 2) for j in range(n))
    main = ((2 * A + 2 * n) ** 2 - (2 * A + n) ** 2) / 2
    print(n, round(-lnD / main, 4))
print("limit quoted by Nair and Chudnovsky: 0.99035")

While reading we also found that, in every case we checked, D is the reciprocal of a whole number, so its size and its divisibility come from one formula again, and that the loss sits on primes of size about n. By Pritsker's argument, any fixed weight of this kind gives a constant below 1, which is why the proof needs a parameter that grows.

The period of a CM curve carries γ − L′/L(1, χ)

On the size page the period of the field carries exactly the constants of the prime count. For an imaginary quadratic field this is the formula of Lerch, Chowla and Selberg, usually written at s = 0. The program computes the same number twice: once at s = 0, and once at s = 1 in the form the proof's main term uses, with γ − L′/L(1, χ). Both are evaluated from the L-function itself.

# The period of a CM curve carries gamma - L'/L(1, chi).
# Lerch, Chowla-Selberg: h = -(1/2) L'/L(0, chi) - (1/4) ln d - (1/2) ln(2 pi).
# Moved to s = 1 by the functional equation, the same number is
# h = -(1/2) (gamma - L'/L(1, chi)) + (1/4) ln d - ln(2 pi).
# Both sides are computed independently from the L-function.
from mpmath import mp, mpf, dirichlet, log, pi, euler

mp.dps = 30

def chi_table(d):
    # the quadratic character of Q(sqrt(-d)), as a list of values mod its conductor
    if d == 4:
        return [0, 1, 0, -1]
    if d == 8:
        return [0, 1, 0, 1, 0, -1, 0, -1]
    return [0] + [1 if pow(k, (d - 1) // 2, d) == 1 else -1 for k in range(1, d)]

for d in (3, 4, 7, 8):
    chi = chi_table(d)
    l0, dl0 = dirichlet(0, chi), dirichlet(0, chi, 1)
    l1, dl1 = dirichlet(1, chi), dirichlet(1, chi, 1)
    h_at_0 = -dl0 / (2 * l0) - log(d) / 4 - log(2 * pi) / 2
    h_at_1 = -(euler - dl1 / l1) / 2 + log(d) / 4 - log(2 * pi)
    print(d, mp.nstr(h_at_0, 12), mp.nstr(h_at_1, 12), mp.nstr(abs(h_at_0 - h_at_1), 3))

Green's weights tend to 1 − 1/g

On the page on few bad members, each member of the family carries a label at two auxiliary primes: a polynomial over the field with g elements. A label without repeated factors has weight 1/∏(gdeg P − 1) over its irreducible factors P. The program adds up these weights exactly, in fractions.

# Green's weights for labels over F_g.
# A label is a monic squarefree polynomial of degree r with nonzero constant term.
# Its weight is the product over its irreducible factors P of 1 / (g^deg P - 1).
# The total weight of all labels of degree r tends to 1 - 1/g.
from fractions import Fraction

def irreducible_counts(g, r):
    # number of monic irreducible polynomials of each degree over F_g, Gauss's formula
    def mobius(n):
        res, m, p = 1, n, 2
        while p * p <= m:
            if m % p == 0:
                m //= p
                if m % p == 0:
                    return 0
                res = -res
            p += 1
        return -res if m > 1 else res
    N = {d: sum(mobius(d // e) * g**e for e in range(1, d + 1) if d % e == 0) // d
         for d in range(1, r + 1)}
    N[1] -= 1          # drop P = x: the constant term must be nonzero
    return N

def total_weight(g, r):
    poly = [Fraction(0)] * (r + 1)
    poly[0] = Fraction(1)
    for d, count in irreducible_counts(g, r).items():
        w = Fraction(1, g**d - 1)
        for _ in range(count):          # each irreducible is used at most once
            for k in range(r, d - 1, -1):
                poly[k] += poly[k - d] * w
    return poly[r]

for g in (5, 7, 11):
    row = [float(total_weight(g, r)) for r in (2, 4, 6, 8)]
    print(g, [round(v, 4) for v in row], "1 - 1/g =", round(1 - 1 / g, 4))

Where 1801 comes from

On the prohibition page the rank of the unitary group is at least 1801, and we call it a safety margin. The archive asks for 120·n·q3/2 ≤ n³ with q ≤ n/2. At q = n/2 this becomes n ≥ (120 / 23/2)² = 1800 exactly.

# Where 1801 comes from.
# The archive needs 120 n q^(3/2) <= n^3 with q <= n/2.  At q = n/2 this reads
# 120 (n/2)^(3/2) <= n^2, that is n >= (120 / 2^(3/2))^2 = 1800 exactly.
import math

print("(120 / 2^1.5)^2 =", (120 / 2**1.5) ** 2)
for n in (1799, 1800, 1801):
    print(n, 120 * n * (n / 2) ** 1.5 <= n**3)

So 1801 is the first whole number strictly past the exact threshold 1800. We found this inequality in a branch of the archive that the final proof does not use; on the path the same threshold appears in a bound that holds from n = 900 on, and the inequalities stated under the condition r ≥ 1801 already hold from n = 2. That is why we read 1801 as a margin.

The live checks on the other pages

  • Stepanov's method: a live count of I₁, I₋₁, I₀.
  • A Frobenius at every inert prime: the congruence with x + xp² and the radius of the p-adic exponential.
  • The right size: the lemniscate constant from γ − L′/L(1, χ).
  • The ladder of lifts: the identity that makes the added blocks cancel.
  • Few bad members: the share of degenerate matrices in GL2(Fq).
  • The balance: the best length of the ladder, x/m + m against x/m + m².

What these checks do not do

This page is our work, not the author's and not a part of the archive. The programs run in seconds on an ordinary computer and use only the Python standard library, except the CM check, which needs mpmath. They test statements in small cases; none of them checks the archive's statements themselves, which the machine has already checked.
